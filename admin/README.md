# Admin — админка A-SERVICE (admin.a-service.asia)

Next.js 14 (App Router) + TypeScript + Tailwind + React Query + Recharts.
Дизайн — фирменный стиль A-SERVICE (фиолетовая палитра, Inter/Manrope).

## Разделы

- **Дашборд** — мониторинг сайта за период (просмотры, уникальные посетители,
  клики WhatsApp/звонки, открытия анкеты, заявки), суммы сделок по дням,
  действия по страницам, график посещаемости, график заявок, последние заявки.
- **Заявки** — список с поиском/фильтрами/пагинацией, карточка заявки
  (статус, ответственный, сумма сделки, заметки, вложение), экспорт Excel.
  В карточке запроса профиля указаны контакты клиента и язык материала. Кнопка
  «Скачать PDF для ручной отправки» выдаёт менеджеру файл на языке запроса.
  Менеджер прикладывает файл к письму в своей рабочей почте. Журнал показывает
  статус уведомления менеджеру и, для старых запросов, историю писем клиенту.
- **Действия** — полный журнал событий посетителей с фильтрами.
- **Контент** — блоки страниц лендинга (тексты, порядок, вкл/выкл).
- **SEO** — title/description/keywords/og-image всех 170 страниц.
- **Сотрудники** — роли ADMIN/MANAGER (только для админа).
- **Настройки** — профиль, смена пароля, push-уведомления, контакты сайта.

Интерфейс на двух языках (RU/ҚАЗ), PWA с push-уведомлениями о новых заявках.

## Запуск

```bash
cd admin
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:8010
npm run dev                  # http://localhost:3000
```

Прод: `npm run build && npm start`, NEXT_PUBLIC_API_URL — адрес API.
Все запросы идут через rewrite `/api/*` → бэкенд (без CORS-проблем).
